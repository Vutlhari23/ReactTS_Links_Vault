Links Vault.

A responsive web application built with React and TypeScript that allows users to  store links,  edit,
 delete and search Link they want. The application provides a simple  and interactiv interface for storing data using the localStorage.

 Features

 * Add new Links with a title, URL, description and tags.
 * Edit existing links.
 * Delete links with a confirmation.
 * Search links
 * Saves links using Local Storages.

Technologies Used.

 * React
 * CSS Module
 * Local Storage
 * React Hooks

Follow the following instructions to run the project.


 1. Clone the Repository

    git clone <respository-url>

2. Navigate to the project folder.

   cd Hyper_Link

3. Install the dependencies.

    npm install
   
5. Start the development server.

   npm run dev
